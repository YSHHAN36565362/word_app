# 프롬프트: 일본어 문법을 "단어처럼" 암기하는 카드 만들기 (문형 1개 = 카드 1개)
# 사용법: "프롬프트 시작" ~ "프롬프트 끝" 사이를 AI에 붙여 넣고, 맨 아래 Input Data의 [ ] 부분에 문법 목록을 넣는다.
# 결과를 받으면: 맨 끝의 "=== 진행률 ===" 줄(카드 목록 아님)은 지우고, word_list/Japanese/<N1|N2|N3 …>/YYYY-MM-DD_이름_문법 단어.txt 로 저장한다.
# 저장 후 GitHub Desktop으로 커밋·푸시 → Vercel 재배포(1~2분) 후 앱에 나타남.
# 토큰 한도로 끊기면 진행률 줄의 "다음" 항목부터 이어서 다시 요청한다.

----- 프롬프트 시작 -----
Role
당신은 한국인 학습자를 위한 JLPT 문법 암기 카드 제작자입니다. 문법 표현을 "단어를 외우듯" 한 장의 카드로 만듭니다.
결과물은 word_app(Next.js 기반 단어 암기 앱)의 힌트 파서가 그대로 읽는 .txt 카드 목록입니다.
(작문 카드처럼 문법당 여러 문장을 만들지 않습니다. 문법 1개 = 카드 1개, 예문은 카드당 딱 1개입니다.)

=== 절대 준수: 파싱 안전 규칙 ===
1. 한 카드 = 빈 줄 없는 연속된 줄 묶음. 카드 내부에 빈 줄 절대 금지. 카드와 카드 사이만 빈 줄 정확히 1개.
2. 1번째 줄 = 문형 원형 그대로 (예: のに, 〜さえ〜ば). 콜론, 읽는 법, 괄호 설명 금지.
   → 이 줄이 앱에서 "문제"로 출제되므로 뜻이 노출되면 안 됩니다.
3. 2번째 줄 = 한국어 뜻(히라가나 독음)  예: ~는데(도)(のに) / ~하기만 하면(さえば)
4. 3번째 줄부터는 "줄 맨 앞 대괄호 태그"로만 구간을 구분합니다. 허용 태그는 아래 4개뿐입니다.
   [종합] [치트키] [장면] [예문]
   (활용이 있는 문형은 [활용], 혼동 문형이 있으면 [헷갈리는 단어]를 선택적으로 추가 가능. 그 외 새 태그 금지)
5. 부등호 < > 금지. 마크다운 볼드(**), 이탤릭(*), 헤더(#), 코드블록 금지. 강조는 「」, →, · 만 사용.
6. 카드 목록 사이에 인사말·설명을 끼우지 마십시오.
7. 입력 순서를 바꾸지 마십시오. 같은 문형이 중복되면 첫 번째만 만듭니다.

=== 카드 템플릿 (반드시 이 순서) ===
[문형]
[한국어 뜻]([히라가나 독음])
[종합] 이 문형의 뜻과 뉘앙스·쓰임·품사(조사/접속 표현 등)를 1~2문장. 접속 형태가 까다로우면 "접속: …"을 덧붙임. 유사 문형이 있으면 "유사: 표현(뜻)" 덧붙임.
[치트키] "한국어 유사발음 문장" → 문형=발음→뜻   (두괄식 훅, 한 줄. 억지스러워도 소리가 겹치게)
[장면] 3초 안에 시각화되는 상황 1줄
[예문] 일본어 문장(한국어 발음) = "한국어 번역"   (딱 1개, 짧고 자연스럽게, 해당 문형이 눈에 띄게)

=== 예시 ===
のに
~는데(도)(のに)
[종합] 역접·불만·의외를 나타내는 조사. 앞의 내용에서 당연히 예상되는 결과와 다른 결과가 나왔을 때, 아쉬움이나 불만의 뉘앙스를 담아 사용함
[치트키] "노니! 노력했는데도 니(너무해) 결과가 안 좋다" → のに=노니→~는데도
[장면] 우산을 챙겼는데도 비를 쫄딱 맞고 투덜대는 장면
[예문] 頑張ったのに、失敗した(간밧타노니, 싯파이시타) = "열심히 했는데도 실패했다"

〜さえ
~조차, ~마저(さえ)
[종합] 극단적인 예를 들어 "그것마저도 그러하니 다른 것은 말할 것도 없다"는 뉘앙스를 강조하는 조사. 명사·동사 등에 접속하여 "~조차, ~마저"의 의미를 더함
[치트키] "사에! 사소한 것사에 놓쳤다" → さえ=사에→~조차
[장면] 전문가조차 풀지 못하는 어려운 문제를 마주한 장면
[예문] 子供さえ知っている(코도모사에 싯테이루) = "아이조차 알고 있다"

〜さえ〜ば
~하기만 하면(さえば)
[종합] 「さえ」와 가정형 「〜ば」가 결합한 문형으로, 다른 조건은 다 필요 없고 오직 그 한 가지 조건만 충족되면 됨을 강조하는 표현
[치트키] "사에바! 사(이것)사에 있으바(있으면) 충분해" → さえば=사에바→~하기만 하면
[장면] 딱 하나의 재료만 있으면 요리가 완성되는 상황
[예문] 時間さえあれば行ける(지칸사에 아레바 이케루) = "시간만 있으면 갈 수 있다"

=== 레벨·품질 기준 ===
· 해당 JLPT 레벨 범위의 뜻만 쓰고, 뜻은 가장 일반적인 1~2개로 제한. 확실하지 않으면 지어내지 말고 생략.
· 경어(존경/겸양)·부사·접속사·지시어도 같은 템플릿으로 처리(뜻 줄에 〈겸양〉 같은 표기는 한국어 뜻 안에 그대로 유지).
· 입력에 한국어 뜻만 있고 문형이 없는 항목은 문맥상 가장 유력한 문형을 추정해 1번째 줄에 쓰되, 확신이 없으면 건너뛰고 진행률 줄에 "보류: …"로 적는다.
· [종합]에는 예문에 쓰인 일반 어휘 설명을 넣지 않는다(문형 설명만).
· [치트키]는 문형 소리와 한국어 소리가 실제로 겹쳐야 하며, 뜻으로 연결되는 짧은 문장으로 쓴다.

=== 출력 분량 및 진행률 (필수) ===
· 토큰 한도로 잘리지 않도록 적절한 개수(약 40~60카드)에서 끊되, 카드 도중에 끊지 마십시오.
· 맨 마지막에 빈 줄 2개를 둔 뒤 아래 한 줄을 반드시 추가:
=== 진행률: [완료 수] / [전체 수] (XX%) | 다음: [다음 문형] ===
