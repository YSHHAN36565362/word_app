## 파트별 PageHeader 일러스트 아이디어 (텍스트, 이미지는 사용자가 직접 첨부 예정)

각 파트 헤더의 색 배지(지금은 "학"/"연"/"매"/"시"/"오"/"설" 같은 한 글자) 자리에 넣을
작은 일러스트 아이디어입니다. 배지가 44px 안팎으로 작게 표시되므로, 배경이 단순하고
피사체가 하나뿐인 그림이 좋습니다.

- **학습**: 책상에 앉아 책을 펼쳐 읽고 있는 학생 한 명. 연필을 들고 있어도 좋음 —
  "차분히 훑어본다"는 느낌.
- **연습**: 연필 한 자루 아이콘, 또는 손으로 무언가를 반복해서 쓰는 모습 — "반복
  연습"의 느낌을 주는 단순한 사물/동작.
- **매칭게임**: 퍼즐 조각 두 개가 딱 맞춰지는 모습(직소 퍼즐 아이콘) — "짝을 맞춘다"는
  의미가 바로 전달됨.
- **시험**: 줄이 그어진 답안지/시험지 한 장 아이콘(사람 없이 종이만) — 채점 표시(빨간
  동그라미 등)가 살짝 보이면 더 좋음.
- **오답노트**: 큰 × (엑스) 표시 아이콘, 또는 노트에 빨간 ×가 그려진 모습.
- **설정**: 톱니바퀴(기어) 아이콘 — 겹쳐진 기어 2개도 좋음.

## 난이도별(모름·헷갈림·조금 앎·완벽함) 반응 일러스트 아이디어

지금은 정답(조금 앎+완벽함)/오답(모름+헷갈림) 두 그룹으로만 나뉘어 있는데, 4단계
각각 다른 느낌의 일러스트를 쓰고 싶다는 요청에 따른 텍스트 설명입니다. 이미지는
irasutoya.com 같은 무료 사이트에서 찾아 첨부하면 됩니다.

- **모름 (0) — 가장 절망적/코믹한 반응**: 충격받아 얼어붙은 표정, 넋 놓고 하늘을
  보는 모습, 무릎 꿇고 좌절하는 모습, 진땀을 뻘뻘 흘리는 모습처럼 "완전히 못 맞혔다"는
  걸 과장되게 보여주는 그림. (기존에 넣어둔 해고당한 회사원, 백기 든 사람, 벼 베는
  농부 같은 유머러스한 그림들이 이 칸에 잘 어울림.)
- **헷갈림 (40) — 애매하고 갸우뚱한 반응**: 고개를 갸우뚱하는 모습, 머리 위에 물음표가
  여러 개 떠 있는 모습, 안경을 고쳐 쓰며 고민하는 모습, 양손을 저울처럼 들고 고민하는
  모습 — "확실친 않지만 뭔가 걸린다"는 느낌.
- **조금 앎 (60) — 안도 섞인 반응**: 이마의 땀을 손등으로 닦는 모습, "휴~" 하고 가슴을
  쓸어내리는 모습, 반신반의하며 손가락으로 브이(V)를 하는 모습 — "아슬아슬하게
  맞혔다"는 안도감.
- **완벽함 (100) — 자신감 넘치는 반응**: 트로피를 들어 올리는 모습, 팔짱을 끼고
  당당하게 웃는 모습, 폭죽이 터지는 배경 앞에서 승리 포즈를 취하는 모습 — 기존의 주먹
  불끈 쥐는 이미지와 같은 계열로, 확신에 찬 승리감을 주는 그림.

## 이번 라운드에서 판단이 필요했던 것 / 남겨둔 제안

- **모름·헷갈림의 SRS 간격**: 처음엔 "내일"로 미루는 안을 그대로 구현했는데, 사용자가
  "내일까지 미루면 오늘 안에 다시 볼 기회가 없어진다"고 지적해 즉시(간격 0) 방식으로
  되돌렸습니다. 현재는 조금 앎(3일)·완벽함(7일)만 날짜 기준으로 미뤄지고, 모름·헷갈림은
  세션 내 재배치(queue.ts)에 맡겨져 있습니다.
- **`N2` 폴더 단어 수(약 1,753개)가 하루 학습량으로는 너무 많다는 지적**: 구조적으로
  "전체 폴더를 한 번에 다 풀어야 하는" 강제가 없다는 점을 먼저 짚고 싶습니다 — 이미
  (1) 연습은 15개 단위 라운드로 쪼개져 있고, (2) 파일 선택 화면에서 원하는 날짜/묶음만
