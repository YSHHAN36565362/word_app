# 2026-08-24 — 채점·진행률 개선

## 한 일
- 방향키(↑↓←→)/WASD/키패드 숫자로도 연습 채점(완벽함/조금앎/헷갈림/모름)을 할 수
  있도록 단축키 추가. 키패드는 NumLock 상태와 무관하게 물리 키 코드(`e.code`)로
  구분해서, 맨 위 숫자 키와 겹치지 않게 함.
- 연습/학습을 종료했다가 다시 들어오면 체크박스·학습 대시보드가 복원되지 않던
  버그 수정 (FileSelector가 focus mode 진입/이탈 시 언마운트되면서 상태가 꼬였던 것).
- "조금 앎(60점)"도 "완벽함(100점)"과 함께 완료로 집계하도록 변경 — 예전엔 완벽함만
  완료로 쳐서 진행률이 잘 안 올라간다는 의견이 있었음. 완벽함/조금 앎으로 채점한
  단어만 모아보는 "복습" 페이지를 새로 추가.
- 단어를 빠르게 연속으로 넘길 때, 서버 응답이 보낸 순서와 다르게 도착해서 오래된
  응답이 최신 진행 상황을 덮어써버리는 race condition 수정 (사용자별·파트별로
  저장 요청을 큐에 줄 세워 처리).
- 채점 직후 화면 전체가 초록/빨강으로 잠깐 번쩍이는 피드백, 완료 화면 색종이(컨페티)
