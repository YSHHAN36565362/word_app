### 주제별 개선 내역

#### 연습 큐 / 복습

- **자기 평가를 4단계로 세분화** — 맞음/틀림 2지선다 대신 완벽함(100)·조금 앎(60)·헷갈림(40)·모름(0)으로 나누고, 단계마다 큐에 다시 꽂는 위치를 다르게 했습니다. 완벽함만 즉시 완료 처리하고 나머지 세 단계는 모두 재등장시켜, "한 번 더 확인하고 싶다"는 의견과 "진행률이 안 오른다"는 의견 사이의 균형을 잡았습니다.
- **재삽입 위치를 구간에서 무작위로** — 고정 위치면 단어가 아니라 순서를 외우게 되므로 구간 안에서 무작위로 뽑고, 라운드 크기 기준으로 계산하며, 방금 본 단어가 바로 다음 카드로 나오지 않도록 최소 3장 간격(`MIN_GAP`)을 보장합니다. 채점 버튼의 "N~M번째" 표시도 같은 함수에서 가져와 실제 동작과 항상 일치합니다.
- **숙련도를 세션 밖으로 영구 저장** — 예전에는 큐가 세션 안에서만 동작해 브라우저를 닫으면 채점 결과가 사라졌습니다. 이제 단어별 최신 점수를 Supabase(`word_mastery`)에 저장하고, 다음 연습·시험에서 점수가 낮은 단어가 먼저 나옵니다.
- **복습 화면** — 완벽함/조금 앎으로 끝낸 단어만 모아 다시 연습할 수 있고, 다시 헷갈리는 단어는 개별로 "초기화"해 우선 출제로 되돌릴 수 있습니다. "복습 완료"로 목록에서 제거도 가능합니다.
- **간격 반복(SRS) 단순화** — 맞힐 때마다 간격이 늘어나던 방식(SuperMemo-2)이 4단계 채점과 맞지 않아, 완벽함은 7일 후·조금 앎은 3일 후라는 점수별 고정 간격으로 바꿨습니다. 복습일이 안 된 단어는 그날 연습에서 제외되고, 기한이 된 단어는 "오늘의 복습"에 모입니다.
- **라운드 단위 마이크로 러닝** — 연습을 라운드(기본 15개, 5~50개 조절 가능)로 쪼개 라운드마다 완료 화면을 보여주고, 진행률 바도 라운드 기준으로 채워집니다. 세 번 이상 헷갈림·모름이면 "자주 틀리는 단어" 배지를 붙입니다.
- **채점 되돌리기** — 잘못 누른 점수를 "되돌리기"(Backspace)로 취소합니다. 화면의 큐·진행률뿐 아니라 서버에 저장된 숙련도(SRS 간격 포함)도 채점 전 값으로 되돌립니다.
- **세션 요약 화면** — 끝났을 때 한 줄 안내 대신 단계별 채점 횟수, 총 횟수, 소요 시간, 완벽+조금 앎 비율을 보여줍니다.

#### 진행 상황 저장 / 이어하기

- **학습 대시보드와 "이 학습 다시 하기"** — 파일 조합별 진행률(`42% (99 / 236개 완료, 137개 남음)`)과 이전 조합 드롭다운을 제공하고, 선택하면 파일·모드·큐 위치가 그대로 복원됩니다.
- **기기별 기록 분리** — 같은 번호를 여러 기기에서 쓸 때 나중에 저장한 기기가 이전 기록을 조용히 덮어쓰던 문제를 고쳤습니다. 기기마다 별도 기록을 남기되 번호만 같으면 어느 기기에서든 이어받습니다. 기기에 이름을 붙일 수 있고, 삭제는 기기별로 하나씩만 되어 다른 기기 기록이 실수로 지워지지 않습니다.
- **오프라인/네트워크 단절 대응** — 진행 큐(`progress`)와 요약(`learning_log`)을 저장할 때마다 이 기기의 localStorage에도 즉시 사본을 남겨, 네트워크가 끊기거나 Supabase가 미설정이어도 같은 기기에서는 이어하기가 동작합니다.
- **저장 순서 꼬임 수정** — 단어를 빠르게 넘길 때 늦게 도착한 오래된 응답이 최신 진행 상황을 덮어쓰던 버그를, `progress`·`wrong_notes` 쓰기를 (사용자, 파트)별 큐로 직렬화해 해결했습니다.
- **학습 기록 관리** — 설정에서 학습/연습/시험/지문 기록을 목록으로 보고 개별 삭제할 수 있고(연습 파트는 "이어서 연습하기" 카드와 함께 정리), 목록 로딩 실패 시 "다시 시도" 버튼이 뜹니다.

#### 한자 학습

- **한자 팝업** — 문장 속 한자 단어에 마우스를 올리거나 탭하면 히라가나 읽기와 한자별 정보(한국 한자음 · 일본 음독/훈독 · 영어 뜻)가 뜹니다. 정답·힌트를 보기 전에는 읽기가 미리 보이지 않습니다.
- **읽기별 예시 단어** — 한자의 읽기 하나당 단어 하나를 붙입니다. 단어 안에서 그 한자가 실제로 어떤 읽기로 읽혔는지를 함께 쓰인 한자의 읽기·송리가나까지 대조해 판별하고, 흔히 쓰는 단어를 우선합니다. 맞는 단어가 없는 드문 읽기는 비워 둡니다.
- **가나 단어 팝업** — 한자 없이 쓰인 부사·접속사·동사·형용사·명사·가타카나어도 뜻을 보여줍니다. 활용형은 기본형으로 찾고(できれば → できる), 단어장에 실린 단어는 한국어 뜻을 함께 보여줍니다.
- **종류별 켜기/끄기** — 필요한 종류만 남기도록 학습·연습 진행 중 설정에서 바로 바꿀 수 있고, 기기에 저장됩니다.
- **데이터는 미리 받아 저장** — 예시 단어와 뜻은 빌드용 스크립트가 한 번 받아 `src/data/`에 JSON으로 저장합니다. 학습 중에는 외부 서버를 부르지 않아 빠르고, 외부 서비스가 멈춰도 동작합니다.
- **한자 힌트 구간 설정** — 한자 분해(음독/훈독/어원) 힌트는 구간별로 색·크기를 바꾸거나 숨길 수 있고, 연습 화면에서 "한자 크기"를 바로 조절할 수 있습니다.

#### IT 학습

- **자격증 단어장** — `word_list/_IT/`에 정보처리기사 실기(이론 정리·족보·두음 암기), 빅데이터분석기사 필기(1~4단원) 단어장이 있어, 일본어와 같은 학습·연습·시험·복습 흐름으로 외울 수 있습니다.
- **용어와 설명을 카드로** — 용어를 앞면, 정의·암기 요령을 뒷면/힌트로 두고, 4단계 자기 평가와 간격 반복으로 약한 용어가 먼저 나옵니다.
- **순서대로 연습 · 공유 링크** — 단원 순서 그대로 외우는 "순서대로 연습"과, 같은 단어장에서 바로 시작하는 공유 링크를 지원합니다.

#### 단어장 데이터

- **저장소 자체를 데이터 계층으로** — 읽기는 `word_list/` 폴더를 서버가 파일시스템에서 직접 읽어 GitHub API 호출과 요청 한도를 없앴고, 추가만 서버가 GitHub Contents API로 커밋합니다(토큰이 브라우저에 노출되지 않음).
- **진행 저장을 GitHub 커밋에서 Supabase로** — 단어를 넘길 때마다 커밋하던 방식을 바꿔 더 빠르고 커밋 히스토리도 깨끗해졌습니다.
- **파서 개선** — 콜론 구분/줄 구분 두 형식을 자동 판별하고, 전각 콜론을 정규화하며, (단어, 뜻, 힌트)가 모두 같은 항목은 자동 중복 제거합니다.

#### 추가한 기능

- **연속 학습일(스트릭)**, **즐겨찾기(별표) 단어**, **매칭 게임**(최고 기록 저장), **발음 듣기**(`S`), **손글씨 메모장(memo)**(애플펜슬만 입력, 손바닥 터치 무시), **오늘의 목표 + 진행 링**, **학습 히트맵 / 숙련도 분포 / 복습 예보**, **세션 요약 화면**, **채점 되돌리기**를 추가했습니다.
- **처음 쓰는 사람을 위한 "설명" 탭** — 파트별 기능과 편의 기능을 화면 캡처와 함께 아코디언으로 안내하는 독립 페이지.

### Streamlit 버전(`word_test`) 대비 달라진 점

- 새로고침 없이 카드가 3D로 뒤집히고, 하단 탭 + PWA로 홈 화면에 설치할 수 있습니다.
- 진행 상황 저장이 GitHub 커밋에서 Supabase로 바뀌어 빠르고 커밋 히스토리가 깨끗합니다.

- 파일 조합별 진행 기록, 학습 대시보드, 이어하기가 생겼습니다.
- "떠다니는 메모장", "세션 킵얼라이브" 같은 Streamlit iframe 특유의 우회 기능은 필요 없어져 포팅하지 않았습니다.

### テーマ別の改善内容

#### 練習キュー / 復習

- **自己評価を4段階に細分化** — 正解/不正解の二択をやめ、完璧(100)・少し分かる(60)・曖昧(40)・分からない(0)に分け、段階ごとにキューへ再挿入する位置を変えました。完璧だけを即完了とし、残り3段階は全て再登場させることで、「もう一度確認したい」という声と「進捗率が上がらない」という声のバランスを取りました。
- **再挿入位置を区間からランダムに** — 位置が固定だと単語ではなく順番を覚えてしまうため区間内でランダムに選び、ラウンドサイズを基準に計算し、直前の単語がすぐ次のカードにならないよう最低3枚の間隔(`MIN_GAP`)を保証します。採点ボタンの「N~M番目」表示も同じ関数から取得し、実際の動作と常に一致します。
- **習熟度をセッションを超えて永続保存** — 以前はキューがセッション内だけで動作し、ブラウザを閉じると採点結果が消えていました。今は単語ごとの最新スコアをSupabase(`word_mastery`)に保存し、次の練習・試験でスコアが低い単語ほど先に出ます。
- **復習画面** — 完璧/少し分かるで終えた単語だけを集めて再練習でき、怪しくなった単語は個別に「初期化」して優先出題に戻せます。「復習完了」でリストから外すこともできます。
- **間隔反復(SRS)の単純化** — 正解するたびに間隔が広がる方式(SuperMemo-2)が4段階評価と噛み合わなかったため、完璧は7日後・少し分かるは3日後という点数別の固定間隔に変更。復習日前の単語はその日の練習から除外し、期限が来た単語は「今日の復習」に集まります。
- **ラウンド単位のマイクロラーニング** — 練習をラウンド(デフォルト15語、5〜50語で調整可)に分割し、ラウンドごとに完了画面を表示、進捗バーもラウンド基準で満ちます。3回以上曖昧・分からないと採点された単語には「よく間違える単語」バッジを表示します。
- **採点の取り消し** — 誤って押した点数を「取り消し」(Backspace)で戻せます。画面のキュー・進捗率だけでなく、サーバーに保存された習熟度(SRS間隔含む)も採点前の値に戻します。
- **セッションサマリー画面** — 終了時に一行の案内ではなく、段階別の採点回数、合計回数、所要時間、完璧+少し分かるの割合を表示します。

#### 進捗の保存 / 再開

- **学習ダッシュボードと「この学習をもう一度」** — ファイルの組み合わせごとの進捗率(`42% (99 / 236個完了、137個残り)`)と過去の組み合わせのドロップダウンを提供し、選ぶとファイル・モード・キューの位置がそのまま復元されます。
- **端末ごとの記録を分離** — 同じ番号を複数端末で使うと、後で保存した端末が前の記録を静かに上書きしていた問題を修正。端末ごとに別記録を残しつつ、番号が同じならどの端末からでも続きから再開できます。端末に名前を付けられ、削除は端末ごとに一つずつのため他端末の記録が誤って消えることはありません。
- **ネットワーク断への対応** — 進捗キュー(`progress`)と要約(`learning_log`)を保存するたびにこの端末のlocalStorageへも即座にコピーを残し、ネットワークが切れてもSupabaseが未設定でも、同じ端末内では再開機能が動作します。
- **保存順序の乱れを修正** — 単語を素早くめくったとき、遅れて届いた古い応答が最新の進捗を上書きする不具合を、`progress`・`wrong_notes`への書き込みを(ユーザー, パート)ごとのキューで直列化して解決しました。
- **学習記録の管理** — 設定で学習/練習/試験/文章の記録を一覧し個別に削除できます(練習パートは「続きから練習する」カードと一緒に整理)。一覧の読み込みに失敗したときは「再試行」ボタンが表示されます。

#### 漢字学習

- **漢字ポップアップ** — 文中の漢字の単語にマウスを乗せる/タップすると、ひらがなの読みと漢字ごとの情報(韓国語の音・音読み/訓読み・英語の意味)を表示します。答えやヒントを見る前は読みが表示されません。
- **読み方ごとの例語** — 漢字の読み1つにつき単語を1つ付けます。単語の中でその漢字が実際にどの読みで読まれたかを、一緒に使われた漢字の読みや送り仮名まで照合して判定し、よく使う単語を優先します。合う単語がない珍しい読みは空欄のままです。
- **かな単語のポップアップ** — 漢字を使わない副詞・接続詞・動詞・形容詞・名詞・カタカナ語も意味を表示します。活用形は基本形で検索し(できれば → できる)、単語帳に載っている単語は韓国語の意味も表示します。
- **種類ごとのON/OFF** — 必要な種類だけ残せるよう、学習・練習の途中の設定からすぐ変更でき、端末に保存されます。
- **データは事前に取得して保存** — 例語と意味はビルド用スクリプトが一度取得し、`src/data/`にJSONで保存します。学習中は外部サーバーを呼ばないため速く、外部サービスが止まっても動作します。
- **漢字ヒント区間の設定** — 漢字の分解(音読み/訓読み/成り立ち)のヒントは区間ごとに色・サイズの変更や非表示ができ、練習画面で「漢字サイズ」をすぐ調整できます。

#### IT学習

- **資格の単語帳** — `word_list/_IT/`に情報処理技師 実技(理論まとめ・過去問・頭文字暗記)、ビッグデータ分析技師 筆記(1〜4単元)の単語帳があり、日本語と同じ学習・練習・試験・復習の流れで覚えられます。
- **用語と説明をカードに** — 用語を表、定義・覚え方を裏/ヒントに置き、4段階の自己評価と間隔反復で苦手な用語が先に出ます。
- **順番どおり練習・共有リンク** — 単元の順番のまま覚える「順番どおり練習」と、同じ単語帳からすぐ始められる共有リンクに対応しています。

#### 単語帳データ

- **リポジトリ自体をデータ層に** — 読み取りは`word_list/`フォルダをサーバーがファイルシステムから直接読むためGitHub API呼び出しとリクエスト上限がなくなり、追加のみサーバーがGitHub Contents APIでコミットします(トークンはブラウザに露出しません)。
- **進捗保存をGitHubコミットからSupabaseへ** — 単語をめくるたびにコミットする方式をやめ、高速化しコミット履歴も汚れなくなりました。
- **パーサーの改善** — コロン区切り/行区切りの2形式を自動判別し、全角コロンを正規化し、(単語、意味、ヒント)がすべて一致する項目は自動で重複排除します。

| デプロイ | Vercel・PWA(manifest) | ホスティング、ホーム画面へのインストール |

アプリ内部API: `POST /api/furigana`(文 → ポップアップ情報)、`GET /api/kanji-words?c=漢字`(読み方ごとの例語)、`/api/wordlist`・`/api/wordbook`(単語帳の読み取り・追加)、`/api/config`、`/api/updated-at`。

データスクリプト: `scripts/build-kanji-data.mjs`(漢字情報)、`scripts/build-kanji-words.mjs`(例語)、`scripts/build-kana-words.mjs`(かな単語の意味)。JMdict系のデータはEDRDGのCC BY-SAライセンスに従います。

### 旧Streamlit版(`word_test`)との違い

- リロードなしでカードが3Dで裏返り、下部タブ + PWAでホーム画面にインストールできます。
- 進捗保存がGitHubコミットからSupabaseに変わり、高速でコミット履歴も汚れません。
- 習熟度がセッションを超えて永続保存され、次回の練習・試験でも苦手だった単語が先に出ます。
- ファイルの組み合わせごとの進捗記録、学習ダッシュボード、再開機能が加わりました。
- 「フローティングメモ」「セッションkeep-alive」などStreamlit iframe特有の回避策は不要になったため移植していません。
