〜におうじて
~에 맞추어, ~에 대응하여(におうじて)
[종합] 상황·요구·변화에 맞게 대응할 때 쓰는 문형. 접속: 명사 + に応じて. 유사: ~に合わせて(~에 맞춰)
[치트키] "니오! 우지(우리)가 상황에 맞춰 대응해!" → におうじて=니오-우지떼→~에 맞추어
[장면] 손님 주문에 따라 요리 양을 척척 조절하는 요리사
[예문] 予算に応じて選ぶ(요산니 오-지떼 에라부) = "예산에 맞춰 고른다"

〜途中で
도중에(とちゅうで)
[종합] 어떤 동작이 진행되는 도중을 가리키는 표현. 접속: 동사 사전형·명사の + 途中で
[치트키] "도추(도주)하다 도중에 잡혔다" → 途中=토츄→도중
[장면] 학교 가는 길 한가운데서 갑자기 소나기를 만난 장면
[예문] 帰る途中で雨が降った(카에루 토츄-데 아메가 훗타) = "돌아가는 도중에 비가 왔다"

〜にわたって
~에 걸쳐서(にわたって)
[종합] 시간·범위가 길고 넓게 이어짐을 나타냄. 접속: 기간·범위 명사 + にわたって. 유사: ~を通して
[치트키] "니와! 와따(왔다) 때가 길게 걸쳐서" → にわたって=니와타떼→~에 걸쳐서
[장면] 3일 내내 눈이 쏟아지는 마을 풍경
[예문] 三日間にわたって雨が続いた(믹카칸니 와탓테 아메가 츠즈이타) = "3일에 걸쳐 비가 계속됐다"

何も〜
굳이~(なにも)
[종합] 부정·반문과 함께 "굳이, 구태여 ~할 필요 없다"는 뉘앙스. 유사: ~ことはない
[치트키] "나니모! 뭘 나니(무엇) 굳이 그러냐" → 何も=나니모→굳이
[장면] 사소한 일에 사과하는 친구를 말리는 장면
[예문] 何も泣くことはない(나니모 나쿠 코토와 나이) = "굳이 울 필요는 없다"

〜一方だ
~하기만 하다(いっぽうだ)
[종합] 한 방향으로 계속 변해 가는 상태. 접속: 동사 사전형 + 一方だ. 유사: ~ばかりだ
[치트키] "이뽀! 이빨 뽑으러 갈수록 아프기만 해" → 一方=잇뽀-→~하기만 하다
[장면] 그래프가 계속 오르기만 하는 물가
[예문] 物価は上がる一方だ(붓카와 아가루 잇포-다) = "물가는 오르기만 한다"

〜がたい
~하기 어렵다(がたい)
[종합] 심리적·상황적으로 하기 힘든 일. 접속: 동사 ます형 어간 + がたい. 유사: ~にくい, ~かねる
[치트키] "가따이! 믿기 어려워서 가다이(가대이)" → がたい=가타이→~하기 어렵다
[장면] 믿을 수 없는 뉴스 앞에서 고개를 젓는 사람
[예문] 信じがたい話だ(신지가타이 하나시다) = "믿기 어려운 이야기다"

〜(さ)せていただく
~하다〈겸양〉(させていただく)
[종합] 상대의 허락을 받아 정중하게 행동함을 나타내는 겸양 표현. 접속: 동사 사역형 + ていただく. 유사: ~いたす
[치트키] "사세! 사세요 사세요, 해 보겠습니다" → させていただく=사세떼이타다쿠→~하겠습니다
[장면] 회의에서 정중히 고개 숙이며 발표를 시작하는 직원
[예문] 発表させていただきます(핫표- 사세떼 이타다키마스) = "발표하겠습니다"

〜(さ)せられる
본의 아니게 ~하게 되다〈사역 수동〉(させられる)
[종합] 하기 싫은데 강제로 시키는 대로 하게 됨. 접속: 동사 사역형 + られる. 유사: ~される
[치트키] "사세라! 사세라 시켜서 억지로 샀다" → させられる=사세라레루→억지로 ~하게 되다
[장면] 상사의 명령으로 야근하며 한숨 쉬는 직원
[예문] 残業させられた(잔교- 사세라레타) = "야근을 하게 되었다"

〜たところ
~했더니(たところ)
[종합] 했더니 뜻밖의 결과가 나왔을 때 사용. 접속: 동사 た형 + ところ. 유사: ~たら
[치트키] "타도코로! 타 봤더니 도코(어디)로 가는지 몰랐다" → たところ=타토코로→~했더니
[장면] 문을 열어 봤더니 아무도 없었던 장면
[예문] 行ったところ、閉まっていた(잇타토코로 시맛테이타) = "갔더니 닫혀 있었다"

〜にすぎないとはいえ
~에 지나지 않는다고는 해도(にすぎないとはいえ)
[종합] 「~にすぎない」에 양보 「とはいえ」가 붙은 문형. 접속: 명사·보통형 + にすぎないとはいえ
[치트키] "스기나이! 소문에 지나지 않다고 해도 스기(삼나무)가 흔들렸다" → にすぎない=니스기나이→~에 지나지 않는다
[장면] 소문이라 해도 신경 쓰이는 표정의 사람
[예문] 噂にすぎないとはいえ、気になる(우와사니 스기나이토와이에 키니나루) = "소문에 불과하다 해도 신경 쓰인다"

〜はずだ
틀림없이 ~일 것이다(はずだ)
[종합] 근거가 있는 확신. 접속: 보통형·명사の + はずだ. 유사: ~に違いない
[치트키] "하즈! 하지(夏至)니까 해가 길 거야" → はず=하즈→~일 것이다
[장면] 시간표를 보며 "이제 도착할 때"라고 말하는 사람
[예문] もう着くはずだ(모- 츠쿠 하즈다) = "이제 도착할 것이다"

〜ままで
~대로, ~인 채로(ままで)
[종합] 상태가 그대로 변하지 않음. 접속: 동사 た형·ない형·명사の + まま
[치트키] "마마! 엄마(마마)가 그 채로 두라 하셨다" → まま=마마→~인 채로
[장면] 불을 켜 둔 채 잠든 사람
[예문] 電気をつけたままで寝た(덴키오 츠케타 마마데 네타) = "불을 켠 채로 잤다"

〜上で
~한 후에(うえで)
[종합] 먼저 앞의 일을 한 뒤 다음 단계로 감. 접속: 동사 た형·명사の + 上で. 유사: ~てから
[치트키] "우에! 우에(위)에서 확인한 후에 내려와" → 上で=우에데→~한 후에
[장면] 계약서를 꼼꼼히 읽고 서명하는 장면
[예문] 確認した上でサインする(카쿠닌시타 우에데 사인스루) = "확인한 후에 서명한다"

〜でありながらも
~이면서도(でありながらも)
[종합] 두 성질이 모순됨을 나타냄. 접속: 명사·な형용사 어간 + でありながら. 유사: ~にもかかわらず
[치트키] "아리! 개미가 작은데아리나가라 힘이 세다" → でありながら=데아리나가라→~이면서도
[장면] 신입인데 베테랑처럼 일하는 직원
[예문] 新人でありながらも優秀だ(신진데 아리나가라모 유-슈-다) = "신입이면서도 우수하다"

〜みたいだ
~인 것 같다(みたいだ)
[종합] 구어체 추측·비유. 접속: 명사·보통형 + みたいだ. 유사: ~ようだ
[치트키] "미타! 눈으로 미타(봤다), 그런 것 같다" → みたい=미타이→~인 것 같다
[장면] 하늘을 보며 "비 올 것 같아" 하는 장면
[예문] 雨が降るみたいだ(아메가 후루 미타이다) = "비가 올 것 같다"

とても〜ない
정말이지 ~않다(とても〜ない)
[종합] 도저히 불가능함을 강조하는 부정 표현. 접속: とても + 가능형 부정. 유사: とうてい~ない
[치트키] "토토모! 토토로도 도저히 못 한다" → とても=토테모→도저히
[장면] 산더미 같은 일을 보고 포기하는 장면
[예문] とても食べられない(토테모 타베라레나이) = "도저히 먹을 수 없다"

〜わけではない(必ずしも)
반드시 ~한 것은 아니다(かならずしも〜わけではない)
[종합] 일반적인 생각이 항상 맞지는 않음을 부분 부정. 접속: 必ずしも + 보통형 + わけではない. 유사: ~とは限らない
[치트키] "카나라즈! 가나라도(가난해도) 반드시 불행한 건 아니다" → 必ずしも=카나라즈시모→반드시
[장면] 비싼 가게인데 맛은 평범한 상황
[예문] 高いから必ずしもいいわけではない(타카이카라 카나라즈시모 이이와케데와 나이) = "비싸다고 반드시 좋은 건 아니다"

〜ようがない
~할 방도가 없다(ようがない)
[종합] 방법이 없어서 할 수 없음. 접속: 동사 ます형 어간 + ようがない. 유사: ~わけにはいかない
[치트키] "요가나이! 요가(yoga)도 못 해, 방법이 없어" → ようがない=요-가나이→방도가 없다
[장면] 연락처가 없어 막막한 사람
[예문] 連絡のしようがない(렌라쿠노 시요-가 나이) = "연락할 방도가 없다"

申し上げる
말씀드리다〈겸양〉(もうしあげる)
[종합] 「言う」의 겸양어. 상대를 높일 때 사용. 유사: 申す(말하다)
[치트키] "모시아게! 모시는 분께 올려 말씀드립니다" → 申し上げる=모-시아게루→말씀드리다
[장면] 회장님 앞에서 허리를 숙여 보고하는 직원
[예문] お礼を申し上げます(오레이오 모-시아게마스) = "감사 말씀드립니다"

〜ないでしょうか
~아닐까요?, ~아닐런지요(ないでしょうか)
[종합] 정중하게 부탁·의견을 완곡하게 묻는 표현. 접속: 동사 ない형 + でしょうか. 유사: ~ていただけませんか
[치트키] "나이데쇼! 나이(나이)로 해 주시지 않을런지요" → ないでしょうか=나이데쇼-카→~아닐까요
[장면] 조심스럽게 부탁하는 직원
[예문] 教えてもらえないでしょうか(오시에테 모라에나이데쇼-카) = "가르쳐 주실 수 없을까요"

〜(さ)せてくれる
~하게 해 주다(させてくれる)
[종합] 상대가 나에게 허락해 줌. 접속: 동사 사역형 + てくれる. 유사: ~させてもらう
[치트키] "사세떼쿠레! 사세요, 구레(주다) 허락해 줬다" → させてくれる=사세떼쿠레루→~하게 해 주다
[장면] 부모님이 해외 유학을 허락해 주는 장면
[예문] 留学させてくれた(류-가쿠 사세떼쿠레타) = "유학을 보내 줬다"

〜てほしい
~해 주었으면 좋겠다(てほしい)
[종합] 상대에게 바라는 희망. 접속: 동사 て형 + ほしい. 유사: ~てもらいたい
[치트키] "호시! 별(호시)을 따 줬으면 좋겠다" → ほしい=호시이→원하다
[장면] 친구에게 손을 모으며 부탁하는 장면
[예문] 手伝ってほしい(테츠닷테 호시-) = "도와주었으면 좋겠다"

〜たばかりだ
막 ~한 참이다(たばかりだ)
[종합] 동작 직후의 시점. 접속: 동사 た형 + ばかりだ. 유사: ~たところだ
[치트키] "타바카리! 타자마자 바칼(바로) 내렸다" → たばかり=타바카리→막 ~한
[장면] 막 도착해 가방도 못 내려놓은 사람
[예문] 着いたばかりだ(츠이타 바카리다) = "막 도착했다"

〜かどうか
~인지 어떤지(かどうか)
[종합] 가부 여부를 나타내는 간접의문. 접속: 보통형 + かどうか
[치트키] "카도우카! 카드(card) 우카(우선) 되는지 어떤지" → かどうか=카도-카→인지 어떤지
[장면] 결과를 기다리며 초조한 수험생
[예문] 行くかどうかわからない(이쿠카도-카 와카라나이) = "갈지 어떨지 모르겠다"

〜とか
~라든가, ~라는 식으로(とか)
[종합] 예시를 나열하거나 불확실한 전문. 접속: 보통형 + とか
[치트키] "토카! 도카(어디가)든 이것저것 예를 든다" → とか=토카→~라든가
[장면] 메뉴판에서 이것저것 말하는 사람
[예문] 肉とか魚とか(니쿠토카 사카나토카) = "고기라든가 생선이라든가"

〜すえに
~한 끝에(すえに)
[종합] 긴 과정 끝의 결과. 접속: 동사 た형·명사の + 末に. 유사: ~あげく
[치트키] "스에! 스에서(숲에서) 끝에 길을 찾았다" → 末に=스에니→~한 끝에
[장면] 오래 고민하다 결심하는 장면
[예문] 悩んだ末に決めた(나얀다 스에니 키메타) = "고민 끝에 정했다"

〜まい
~하지 않겠다, ~하지 않을 것이다(まい)
[종합] 부정의 의지·추측. 접속: 동사 사전형(1단: ない형) + まい
[치트키] "마이! 마이(my)는 절대 안 한다" → まい=마이→~하지 않겠다
[장면] 두 번 다시 거짓말 않겠다고 다짐하는 얼굴
[예문] 二度と言うまい(니도토 이우마이) = "두 번 다시 말하지 않겠다"

まいる
오다, 가다〈겸양〉(まいる)
[종합] 「行く・来る」의 겸양어
[치트키] "마이루! 마이(my) 집으로 갑니다" → まいる=마이루→가다(겸양)
[장면] 손님 집을 정중히 찾아뵙는 장면
[예문] すぐ参ります(스구 마이리마스) = "곧 가겠습니다"

むしろ
오히려, 차라리(むしろ)
[종합] 두 가지를 비교해 후자를 택함. 유사: かえって
[치트키] "무시로! 무시당하느니 차라리" → むしろ=무시로→오히려
[장면] 칭찬 대신 비난이 아니라 오히려 칭찬받는 상황
[예문] むしろ嬉しい(무시로 우레시-) = "오히려 기쁘다"

〜になっているだろう
~이 되어 있을 것이다(になっているだろう)
[종합] 변화 후 상태를 추측. 접속: 명사 + になっているだろう
[치트키] "니낫떼! 니(네)가 낫떼(나아서) 건강해져 있겠지" → になっている=니낫떼이루→~이 되어 있다
[장면] 10년 후의 모습을 상상하는 장면
[예문] 明日には元気になっているだろう(아시타니와 겐키니 낫떼이루다로-) = "내일엔 기운을 차렸을 것이다"

〜ても〜なくても
~해도 ~하지 않아도(ても〜なくても)
[종합] 어느 쪽이든 결과 동일. 접속: 동사 て형 + も + ない형 + なくても
[치트키] "테모나쿠테모! 떼모(떼어도) 안 떼어도 똑같아" → ても〜なくても=테모 나쿠테모→해도 안 해도
[장면] 가도 안 가도 똑같은 모임
[예문] 行っても行かなくても同じだ(잇테모 이카나쿠테모 오나지다) = "가도 안 가도 같다"

〜すぎず
너무 ~하지 말고(すぎず)
[종합] ~과하지 않게. 접속: 동사 ます형 어간 + すぎず
[치트키] "스기즈! 스기(杉)나무처럼 너무 높지도 낮지도" → すぎず=스기즈→너무 ~하지 않고
[장면] 적당한 양의 음식을 담는 장면
[예문] 多すぎず少なすぎず(오-스기즈 스쿠나스기즈) = "많지도 적지도 않게"

〜でしかない
~밖에 되지 않다, ~에 불과하다(でしかない)
[종합] 그 정도에 불과함. 접속: 명사 + でしかない. 유사: ~にすぎない
[치트키] "데시카나이! 데시(제자)가 겨우 이것밖에 안 돼" → でしかない=데시카나이→~에 불과하다
[장면] 큰 꿈을 말하지만 현실은 초보인 사람
[예문] ただの噂でしかない(타다노 우와사데 시카나이) = "그저 소문에 불과하다"

〜わけがない

[치트키] "와케가나이! 와, 케(께)서 그럴 리 없나이" → わけがない=와케가나이→~할 리 없다

[예문] そんなことがあるわけがない(손나 코토가 아루 와케가 나이) = "그럴 리가 없다"

〜くらい

〜にこたえて

〜うちに

~도 ~하지 않고(も〜ないで)

〜をとわず

〜ないうちに
~하기 전에(ないうちに)
[종합] 변화가 일어나기 전에 서둘러. 접속: 동사 ない형 + うちに
[치트키] "나이우치니! 날이 없어지기 전에" → ないうちに=나이우치니→~하기 전에
[장면] 잊기 전에 메모하는 장면
[예문] 忘れないうちにメモする(와스레나이 우치니 메모스루) = "잊기 전에 메모한다"

〜ており
~하고 있어서(ており)
[종합] 「ていて」의 문어체. 접속: 동사 て형 + おり
[치트키] "오리! 오리(duck)가 하고 있어서" → ており=테오리→~하고 있어서
[장면] 공지문에 쓰이는 딱딱한 문장
[예문] 現在調査しております(겐자이 쵸-사시테오리마스) = "현재 조사하고 있습니다"

〜にもかかわらず
~(임)에도 불구하고(にもかかわらず)
[종합] 예상과 다른 역접. 접속: 보통형·な형용사 어간 + にもかかわらず
[치트키] "카카와라즈! 가가와(香川)라고 해도 불구하고" → かかわらず=카카와라즈→불구하고
[장면] 아픈데도 출근한 사람
[예문] 雨にもかかわらず来た(아메니모 카카와라즈 키타) = "비가 옴에도 불구하고 왔다"

〜らしい(접미어)
~답다〈접미어〉(らしい)
[종합] 그것에 걸맞은 특성. 접속: 명사 + らしい
[치트키] "라시이! 라시(라면)답게 맛있다" → らしい=라시이→~답다
[장면] 선생님다운 따뜻한 말투
[예문] 男らしい(오토코라시-) = "남자답다"

〜によっては
~에 따라서는(によっては)
[종합] 경우에 따라 다름. 접속: 명사 + によっては
[치트키] "요잇떼와! 요(여)기선 사람에 따라서는" → によっては=니욧테와→~에 따라서는
[장면] 사람마다 취향이 다른 장면
[예문] 人によっては合わない(히토니 욧테와 아와나이) = "사람에 따라서는 안 맞는다"

〜(さ)せる/〜たがる
~하게 하다〈사역〉 / ~하고 싶어하다(させる/たがる)
[종합] 사역은 남을 시킴, たがる는 제3자의 욕구. 접속: 동사 ない형 + せる / 동사 ます형 + たがる
[치트키] "사세루/타가루! 사세루(시키다) / 타가루(탐내다)" → させる=시키다 / たがる=원하다
[장면] 아이에게 채소를 먹이려는 엄마
[예문] 子どもに食べさせる(코도모니 타베사세루) = "아이에게 먹게 한다"

どれだけ〜か
얼마나 ~일까?(どれだけ〜か)
[종합] 정도의 큼을 강조하는 의문. 유사: どんなに~か
[치트키] "도레다케! 도레(어느 것)만큼이나?" → どれだけ=도레다케→얼마나
[장면] 감사의 크기를 말하는 장면
[예문] どれだけ心配したか(도레다케 심파이시타카) = "얼마나 걱정했는지"

ご覧
보심〈존경〉(ごらん)
[종합] 「見る」의 존경. ご覧になる 형태
[치트키] "고란! 고란(고운 눈)으로 보심" → ご覧=고란→보심
[장면] 고객이 상품을 둘러보는 장면
[예문] こちらをご覧ください(코치라오 고란 쿠다사이) = "이쪽을 봐 주세요"

〜(ら)れる
~하게 되다(られる)
[종합] 수동·자발·가능·존경. 접속: 동사 ない형 + れる・られる
[치트키] "라레루! 라레(나)에게 주어졌다" → られる=라레루→~당하다
[장면] 비를 맞고 당황하는 사람
[예문] 先生にほめられた(센세-니 호메라레타) = "선생님께 칭찬받았다"

〜ようならば
~할 것 같으면(ようならば)
[종합] 가정. 접속: 보통형 + ようならば
[치트키] "요-나라바! 요(여)기 같으면" → ようならば=요-나라바→~할 것 같으면
[장면] 컨디션이 안 좋으면 쉬라고 하는 장면
[예문] 無理なようならば休め(무리나요-나라바 야스메) = "무리일 것 같으면 쉬어라"

〜にのぼる
~에 달하다(にのぼる)
[종합] 수량이 큼. 접속: 수량 + にのぼる
[치트키] "노보루! 노보루(오르다) 수치에 달하다" → のぼる=노보루→달하다
[장면] 참가자 수가 늘어나는 그래프
[예문] 一万人にのぼる(이치만닌니 노보루) = "1만 명에 달한다"

〜てからでないと
~한 후가 아니면(てからでないと)
[종합] 먼저 한 뒤에야 가능. 접속: 동사 て형 + からでないと
[치트키] "카라데나이토! 가라, 그 뒤가 아니면" → てからでないと=테카라데나이토→~한 후가 아니면
[장면] 확인 전에는 서명 못 하는 사람
[예문] 見てからでないと決められない(미테카라데나이토 키메라레나이) = "보고 나서가 아니면 정할 수 없다"

〜次第
~하는 대로(しだい)
[종합] 바로 뒤에. 접속: 동사 ます형 어간 + 次第
[치트키] "시다이! 시다이(차례)로 도착하는 대로" → 次第=시다이→~하는 대로
[장면] 도착 즉시 연락하는 직원
[예문] 着き次第連絡します(츠키시다이 렌라쿠시마스) = "도착하는 대로 연락하겠습니다"

うけたまわる
받다〈겸양, 겸손〉(うけたまわる)
[종합] 「聞く・受ける」의 겸양어
[치트키] "우케타마와루! 우케(받아) 타마(구슬) 돌리듯 듣다" → 承る=우케타마와루→받다(겸양)
[장면] 주문을 정중히 받는 점원
[예문] ご注文を承ります(고츄-몬오 우케타마와리마스) = "주문을 받겠습니다"

〜わけにはいかない
~할 수는 없다(わけにはいかない)
[종합] 사정상 할 수 없음. 접속: 동사 사전형·ない형 + わけにはいかない
[치트키] "와케니와! 와케(이유)가 있어 못 가" → わけにはいかない=와케니와이카나이→~할 수는 없다
[장면] 아파도 쉴 수 없는 사람
[예문] 休むわけにはいかない(야스무 와케니와 이카나이) = "쉴 수는 없다"

〜や何かで
~와 같은 것에서〈예시〉(やなにかで)
[종합] 예를 들어 막연히 언급. 접속: 명사 + か何かで
[치트키] "나니카데! 나니(무엇)카든" → 何かで=나니카데→무엇인가로
[장면] 신문이나 TV에서 본 기억을 더듬는 사람
[예문] 雑誌か何かで見た(잣시카 나니카데 미타) = "잡지 같은 데서 봤다"

〜のに
~는데(도)(のに)
[종합] 역접·불만·의외를 나타내는 조사. 앞의 내용에서 당연히 예상되는 결과와 다른 결과가 나왔을 때, 아쉬움이나 불만의 뉘앙스를 담아 사용함
[치트키] "노니! 노력했는데도 니(너무해) 결과가 안 좋다" → のに=노니→~는데도
[장면] 우산을 챙겼는데도 비를 쫄딱 맞고 투덜대는 장면
[예문] 頑張ったのに、失敗した(간밧타노니, 싯파이시타) = "열심히 했는데도 실패했다"

〜たびに
~할 때마다(たびに)
[종합] 반복되는 계기. 접속: 동사 사전형·명사の + たびに
[치트키] "타비니! 다비(여행)할 때마다" → たびに=타비니→~할 때마다
[장면] 지날 때마다 그 가게가 떠오르는 사람
[예문] 会うたびに驚く(아우타비니 오도로쿠) = "만날 때마다 놀란다"

〜かもしれない
~일지도 모른다(かもしれない)
[종합] 불확실한 가능성. 접속: 보통형 + かもしれない
[치트키] "카모시레나이! 가모(鴨)시레나이(몰라)" → かもしれない=카모시레나이→~일지도 모른다
[장면] 하늘이 흐려 비를 걱정하는 사람
[예문] 雨が降るかもしれない(아메가 후루 카모시레나이) = "비가 올지도 모른다"

〜さえ〜ば
~하기만 하면(さえば)
[종합] 「さえ」와 가정형 「〜ば」가 결합한 문형으로, 다른 조건은 다 필요 없고 오직 그 한 가지 조건만 충족되면 됨을 강조하는 표현
[치트키] "사에바! 사(이것)사에 있으바(있으면) 충분해" → さえば=사에바→~하기만 하면
[장면] 딱 하나의 재료만 있으면 요리가 완성되는 상황
[예문] 時間さえあれば行ける(지칸사에 아레바 이케루) = "시간만 있으면 갈 수 있다"

〜において
~에 있어서, ~에서(において)
[종합] 장소·시간·분야를 나타내는 격식 표현. 접속: 명사 + において
[치트키] "니오이테! 냄새(니오이)나는 곳에서" → において=니오이테→~에서
[장면] 본사에서 열리는 회의
[예문] 本社において行う(혼샤니 오이테 오코나우) = "본사에서 실시한다"

〜ものなら
~할 수만 있다면(ものなら)
[종합] 실현 어려운 일의 가정. 접속: 가능 동사 사전형 + ものなら
[치트키] "모노나라! 모노(물건) 나라(나라)도 되돌릴 수 있다면" → ものなら=모노나라→~할 수만 있다면
[장면] 시간을 되돌리고 싶은 사람
[예문] できるものならやりたい(데키루모노나라 야리타이) = "할 수만 있다면 하고 싶다"

ただし
다만, 단(ただし)
[종합] 앞말에 조건·예외를 붙임. 유사: もっとも
[치트키] "타다시! 타다(공짜)다, 다만" → ただし=타다시→다만
[장면] 무료이지만 예약 필수 안내
[예문] 無料。ただし予約が必要だ(무료- 타다시 요야쿠가 히츠요-다) = "무료. 다만 예약이 필요하다"

〜勢いだ
~할 기세이다(いきおいだ)
[종합] 곧 그렇게 될 듯한 기세. 접속: 동사 사전형·명사の + 勢いだ
[치트키] "이키오이! 이끼(숨)오이(노인)도 달릴 기세" → 勢い=이키오이→기세
[장면] 당장 울음을 터뜨릴 듯한 아이
[예문] 泣き出さんばかりの勢いだ(나키다산바카리노 이키오이다) = "울음이 터질 기세다"

ご覧いただく
보시다〈겸손〉(ごらんいただく)
[종합] 「見てもらう」의 겸손 표현
[치트키] "고란이타다쿠! 고란(고운 눈)으로 받아 보시다" → ご覧いただく=고란이타다쿠→보시다
[장면] 전시장에서 작품을 소개하는 직원
[예문] ご覧いただけます(고란 이타다케마스) = "보실 수 있습니다"

〜にすぎない
~에 지나지 않는다(にすぎない)
[종합] 그 정도에 불과함. 접속: 명사·보통형 + にすぎない
[치트키] "스기나이! 스기(삼나무)나이, 지나지 않아" → にすぎない=니스기나이→~에 지나지 않는다
[장면] 대수롭지 않은 변명을 하는 사람
[예문] 言い訳にすぎない(이이와케니 스기나이) = "변명에 지나지 않는다"

〜ならともかく
~이라면 몰라도(ならともかく)
[종합] 앞은 예외, 뒤는 문제. 접속: 명사·보통형 + ならともかく
[치트키] "나라토모카쿠! 나라(奈良)라면 몰라도" → ならともかく=나라토모카쿠→~라면 몰라도
[장면] 아이라면 몰라도 어른은 안 된다는 장면
[예문] 子どもならともかく大人は無理だ(코도모나라토모카쿠 오토나와 무리다) = "아이라면 몰라도 어른은 무리다"

〜てもらう
~해 주다, ~해 받다(てもらう)
[종합] 상대가 나에게 해 줌. 접속: 동사 て형 + もらう
[치트키] "모라우! 모라(몰라)줘서 받았다" → もらう=모라우→받다
[장면] 친구가 이사를 도와주는 장면
[예문] 手伝ってもらう(테츠닷테 모라우) = "도와준다"

〜(さ)せる
~시키다, ~하게 하다〈사역〉(させる)
[종합] 남에게 시킴. 접속: 동사 ない형 + せる・させる
[치트키] "사세루! 사세(사세요)라고 시키다" → させる=사세루→~시키다
[장면] 선생님이 학생들에게 읽게 하는 장면
[예문] 子どもに読ませる(코도모니 요마세루) = "아이에게 읽게 한다"

いたす
하다〈겸양, 겸손〉(いたす)
[종합] 「する」의 겸양어
[치트키] "이타스! 이따가 할게요" → いたす=이타스→하다(겸양)
[장면] 고객 앞에서 정중히 안내하는 직원
[예문] ご案内いたします(고안나이 이타시마스) = "안내해 드리겠습니다"

〜がち
자주 ~함, 일쑤임(がち)
[종합] 좋지 않은 경향. 접속: 명사·동사 ます형 어간 + がち
[치트키] "가치! 가지(茄子)를 자주 먹는 일쑤" → がち=가치→~하기 일쑤
[장면] 감기에 자주 걸리는 사람
[예문] 病気がちだ(뵤-키가치다) = "병치레가 잦다"

〜とおりに
~대로(とおりに)
[종합] 그대로 따름. 접속: 동사 사전형·た형·명사の + とおりに
[치트키] "토오리니! 토리(닭)니 말한 대로" → とおり=토-리→~대로
[장면] 지시받은 대로 따라 하는 장면
[예문] 言われたとおりにやる(이와레타 토-리니 야루) = "들은 대로 한다"

〜にかけては
~에 관한 한(にかけては)
[종합] 그 분야만큼은 최고. 접속: 명사 + にかけては

[장면] 방법이 궁금한 사람
[예문] どうやって作ったか(도-얏테 츠쿳타카) = "어떻게 만들었는지"

〜(よ)うとしないで

[예문] 無理しようとしないで(무리 시요-토시나이데) = "무리하려 하지 말고"

〜べきだ

[종합] 당연한 도리. 접속: 동사 사전형 + べきだ
[치트키] "베키다! 벡키(벗어)다" → べき=베키→~해야
[장면] 약속을 지켜야 하는 사람
[예문] 守るべきだ(마모루베키다) = "지켜야 한다"

〜おかげだ
~덕분이다(おかげだ)
[종합] 감사. 접속: 명사の + おかげだ
[치트키] "오카게다! 오카게(덕분)다" → おかげだ=오카게다→덕분이다
[장면] 성공을 감사하는 사람
[예문] 皆様のおかげです(미나사마노 오카게데스) = "여러분 덕분입니다"

〜に至って
~에 이르러(にいたって)
[종합] 극단적 상황에 도달. 접속: 명사·동사 사전형 + に至って
[치트키] "이타닷테! 이타(痛)닷테" → 至って=이타탓테→이르러
[장면] 최악이 되고서야 깨닫는 사람
[예문] ここに至って(코코니 이탓테) = "이 지경에 이르러"

〜にかかわらず
~에 관계없이(にかかわらず)
[종합] 조건 무관. 접속: 명사 + にかかわらず
[치트키] "카카와라즈! 가가와라즈(관계없이)" → かかわらず=카카와라즈→관계없이
[장면] 나이 상관없는 대회
[예문] 年齢にかかわらず(넨레-니 카카와라즈) = "나이에 관계없이"

いつのまに
어느 틈에(いつのまに)
[종합] 모르는 사이에 어느새
[치트키] "이츠노마니! 이쯤 마니(많이) 변했나" → いつのまに=이츠노마니→어느 틈에
[장면] 비가 그친 하늘
[예문] いつのまにか終わった(이츠노마니카 오왓타) = "어느새 끝났다"

〜反面
~반면(はんめん)
[종합] 반대 측면. 접속: 보통형 + 反面
[치트키] "한멘! 한(半)면" → 反面=한멘→~반면
[장면] 보수는 좋지만 바쁜 일
[예문] 給料がいい反面(큐-료-가 이이 한멘) = "월급이 좋은 반면"

〜でよければ
~로 괜찮다면(でよければ)
[종합] 제안. 접속: 명사 + でよければ
[치트키] "데요케레바! 데(이것)요케레바" → でよければ=데요케레바→~로 괜찮다면
[장면] 시간을 제안하는 직원
[예문] これでよければ(코레데 요케레바) = "이걸로 괜찮다면"

〜ないよう
~하지 않도록(ないよう)
[종합] 방지 목적. 접속: 동사 ない형 + ないよう
[치트키] "나이요-! 나이요-(없도록)" → ないよう=나이요-→~않도록
[장면] 잊지 않도록 메모하는 사람
[예문] 忘れないよう(와스레나이요-) = "잊지 않도록"

〜次第だ
~에 달렸다(しだいだ)
[종합] 결정은 ~에 따름. 접속: 명사 + 次第だ
[치트키] "시다이다! 시다이(차례)다" → 次第だ=시다이다→~에 달렸다
[장면] 성패가 팀워크에 달린 장면
[예문] 君次第だ(키미시다이다) = "너에게 달렸다"

〜ことがある
발생하는 경우가 있다(ことがある)
[종합] 가끔 일어남. 접속: 동사 사전형 + ことがある
[치트키] "코토가아루! 고토(일)가 있다" → ことがある=코토가아루→~하는 경우가 있다
[장면] 눈 오면 길이 막히는 상황
[예문] 遅れることがある(오쿠레루코토가 아루) = "늦는 경우가 있다"

〜なんか
~같은 (것)(なんか)
[종합] 예시 또는 낮춰 말하는 표현. 접속: 명사 + なんか. 유사: ~など
[치트키] "난카! 난(나)가 같은 건" → なんか=난카→~같은 것
[장면] 나 같은 건 안 된다며 손사래 치는 사람
[예문] 私なんかには無理だ(와타시난카니와 무리다) = "나 같은 사람에게는 무리다"

どれほど
얼마나(どれほど)
[종합] 정도의 큼을 강조. 유사: どれだけ
[치트키] "도레호도! 도레(어느)호도(정도)" → どれほど=도레호도→얼마나
[장면] 노력을 헤아려 보는 장면
[예문] どれほど努力したか(도레호도 도료쿠시타카) = "얼마나 노력했는지"

〜といった
~와 같은〈예시, 열거〉(といった)
[종합] 예를 나열. 접속: 명사 + といった + 명사
[치트키] "토잇타! 토(이)잇타(말한)" → といった=토잇타→~와 같은
[장면] 도시락, 샌드위치를 나열하는 장면
[예문] 寿司といった和食(스시토 잇타 와쇼쿠) = "초밥 같은 일식"

〜きり
~한 채(きり)
[종합] 이후 계속 이어지지 않음. 접속: 동사 た형 + きり
[치트키] "키리! 기리(끝)" → きり=키리→~한 채
[장면] 졸업 후 한 번도 못 만난 친구
[예문] 会ったきり(앗타키리) = "만난 채"

〜てみようか
해 볼까?(てみようか)
[종합] 시도 제안. 접속: 동사 て형 + みようか
[치트키] "미요-카! 미요(봐요)카" → みようか=미요-카→해 볼까
[장면] 새 가게에 가 볼까 하는 사람
[예문] 行ってみようか(잇테미요-카) = "가 볼까?"

〜のであれば
~한 것이라면(のであれば)
[종합] 조건. 접속: 보통형 + のであれば
[치트키] "노데아레바! 노데(노)아레바" → のであれば=노데아레바→~한 것이라면
[장면] 하고 싶다면 하라는 말
[예문] 行くのであれば(이쿠노데아레바) = "가는 것이라면"

〜ずつ
~씩(ずつ)
[종합] 균등 배분. 접속: 수량 + ずつ
[치트키] "즈츠! 쯔쯔(찔금씩)" → ずつ=즈츠→~씩
[장면] 두 개씩 나눠 주는 사람
[예문] 二つずつ(후타츠즈츠) = "두 개씩"

〜までになる
~할 정도가 되다(までになる)
[종합] 결과 상태에 이름. 접속: 동사 사전형 + までになる
[치트키] "마데니나루! 마데(까지)니 되다" → までになる=마데니나루→정도가 되다
[장면] 결국 5시간밖에 못 자게 된 사람
[예문] 眠れないまでになった(네무레나이마데니 낫타) = "잠 못 잘 정도가 되었다"

欠かせない
빠뜨릴 수 없다, 필요하다(かかせない)
[종합] 반드시 필요. 접속: 명사 + が欠かせない
[치트키] "카카세나이! 카카(까까)세나이(못 뺀다)" → 欠かせない=카카세나이→빠뜨릴 수 없다
[장면] 팀워크가 필요한 프로젝트
[예문] 水は欠かせない(미즈와 카카세나이) = "물은 빠뜨릴 수 없다"

〜ばよかった
~했으면 좋았을 텐데(ばよかった)
[종합] 후회. 접속: 동사 ば형 + よかった
[치트키] "바요캇타! 바요캇타" → ばよかった=바요캇타→했으면 좋았을 텐데
[장면] 더 일찍 출발할 걸 후회
[예문] 行けばよかった(이케바 요캇타) = "갔으면 좋았을 텐데"

〜ということになる
~라는 것이 된다(ということになる)
[종합] 결과적 귀결. 접속: 보통형 + ということになる
[치트키] "토이우코토니나루! 토이우 코토니나루" → ということになる=토이우코토니나루→~라는 것이 된다
[장면] 결국 중지라는 결론
[예문] 中止ということになる(츄-시토이우 코토니 나루) = "중지가 된다"

〜さえ
~조차, ~마저(さえ)
[종합] 극단적인 예를 들어 "그것마저도 그러하니 다른 것은 말할 것도 없다"는 뉘앙스를 강조하는 조사. 명사·동사 등에 접속하여 "~조차, ~마저"의 의미를 더함
[치트키] "사에! 사소한 것사에 놓쳤다" → さえ=사에→~조차
[장면] 전문가조차 풀지 못하는 어려운 문제를 마주한 장면
[예문] 子供さえ知っている(코도모사에 싯테이루) = "아이조차 알고 있다"

まず
거의, 대체로〈부정〉(まず)
[종합] 뒤에 부정이 오면 "거의 ~않다"
[치트키] "마즈! 마즈(맛이)없다 거의" → まず=마즈→거의
[장면] 올 가능성이 거의 없는 손님
[예문] まずない(마즈나이) = "거의 없다"

〜たび
~할 때마다(たび)
[종합] 반복. 접속: 동사 사전형·명사の + たび
[치트키] "타비! 다비(여행)때마다" → たび=타비→~할 때마다
[장면] 그때마다 가르쳐 주는 선생님
[예문] そのたびに(소노타비니) = "그때마다"

〜たがらないのなら
~하고 싶어하지 않는 것이라면(たがらないのなら)
[종합] 제3자 의지 부정 조건. 접속: 동사 ます형 어간 + たがらないのなら
[치트키] "타가라나이노나라! 타가라(탐내)나이노나라" → たがらないのなら=타가라나이노나라→원하지 않는다면
[장면] 억지로 권하지 않는 장면
[예문] 食べたがらないのなら(타베타가라나이노나라) = "먹고 싶어하지 않는다면"

〜というような

[치트키] "토이우요-나! 토이우(라는) 요-나(같은)" → というような=토이우요-나→라는 듯한

[예문] 謝れというような(아야마레토이우요-나) = "사과하라는 듯한"

〜わけではない
~인 것은 아니다(わけではない)

[치트키] "와케데와나이! 와케(이유)데와 나이" → わけではない=와케데와나이→~인 것은 아니다
[장면] 바쁘다고 오해받는 장면
[예문] 嫌いなわけではない(키라이나와케데와 나이) = "싫은 것은 아니다"

〜ところだ
막 ~하는 참이다(ところだ)
[종합] 동작 직전·중·직후. 접속: 동사 사전형 + ところだ
[치트키] "토코로다! 도코(어디)로다" → ところだ=토코로다→~하는 참
[장면] 막 집을 나서려는 사람
[예문] 出るところだ(데루 토코로다) = "나가려는 참이다"

〜までで
~까지(までで)
[종합] 범위·기한. 접속: 명사 + までで
[치트키] "마데데! 마데(까지)데" → までで=마데데→~까지
[장면] 내일까지면 된다는 장면
[예문] 明日までで結構(아시타마데데 켓코-) = "내일까지면 됩니다"

〜といっても
~라고 해도(といっても)

[치트키] "토잇테모! 토 잇테모(말해도)" → といっても=토잇테모→~라고 해도
[장면] 일본어를 안다지만 인사 정도뿐인 사람
[예문] できるといっても少しだけ(데키루토 잇테모 스코시다케) = "할 수 있다 해도 조금뿐"

〜からすると
~로 보아(からすると)

[장면] 표정을 보고 화난 줄 아는 장면
[예문] 表情からすると(효-죠-카라스루토) = "표정으로 보아"

〜じゃないかと思う

〜にしたら

〜て初めて
~해서야 비로소(てはじめて)
